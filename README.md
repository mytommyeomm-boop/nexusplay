# NexusPlay - Stage 1a

Compose UI shell: theme, 5-tab navigation, splash, device info. No database or file handling yet.

Build: open the folder in AndroidIDE (or any Gradle-capable IDE) and run `assembleDebug`.
Requires JDK 17, internet for the first dependency sync.
If your IDE did not generate `gradlew` and `gradle/wrapper/gradle-wrapper.jar`, create a throwaway
project with package `com.nexusplay.launcher`, copy those two items over, then use these files.
